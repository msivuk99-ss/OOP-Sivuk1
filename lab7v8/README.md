# Лабораторна робота №7: Узагальнені типи (Generics). IRepository з where-обмеженнями та тестами

**Тема:** Узагальнені типи (Generics). IRepository з where-обмеженнями та тестами.  
**Мета:** Навчитися створювати узагальнені інтерфейси та класи, застосовувати `where`-обмеження для типів-параметрів, а також розробляти юніт-тести для перевірки коректності узагальнених реалізацій.  
**Варіант:** 8 (Сутність `TaskItem`: Title, Description, IsCompleted)  

---

## 1. Структура проєкту та короткий опис

* **`IEntity`**: Інтерфейс із властивістю `int Id { get; set; }`, який гарантує наявність ідентифікатора у всіх сутностей.
* **`TaskItem`**: Сутність варіанту 8 із полями `Id`, `Title`, `Description` та `IsCompleted`. Реалізує інтерфейс `IEntity`.
* **`IRepository<T>`**: Узагальнений інтерфейс з обмеженням `where T : IEntity`. Визначає CRUD-операції (`GetById`, `GetAll`, `Add`, `Update`, `Delete`).
* **`InMemoryRepository<T>`**: Узагальнений клас для збереження даних у пам'яті (`List<T>`). Обробляє виняткові ситуації (дублювання ID, оновлення/видалення неіснуючих елементів).
* **`lab7v8.Tests`**: Проєкт на базі xUnit, що містить повне покриття тестами всіх методів `InMemoryRepository<T>`.

## Контрольні запитання

1. **Яка роль `where`-обмежень у Generics? Наведіть приклади їх використання.**  
   `where`-обмеження звужують множину типів, які можна передати замість типу-параметра `T`. Це дозволяє безпечно використовувати методи та властивості цього типу всередині узагальненого класу (наприклад, `where T : IEntity` гарантує наявність властивості `Id`).

2. **Навіщо потрібен шаблон IRepository? Які переваги він дає?**  
   Шаблон `IRepository` абстрагує логіку збереження та отримання даних від бізнес-логіки додатка. Це дозволяє легко змінювати джерело даних (наприклад, замінити `InMemoryRepository` на репозиторій бази даних Entity Framework) без зміни решти коду.

3. **Поясніть, чому юніт-тести є важливими при розробці узагальнених компонентів.**  
   Оскільки узагальнені компоненти призначені для роботи з різноманітними типами даних, юніт-тести дозволяють гарантувати, що CRUD-операції, граничні випадки та обробка помилок працюють коректно і передбачувано для будь-якої сутності.

4. **Які проблеми вирішують Generics порівняно з використанням `object`?**  
   Generics забезпечують сувору типізацію на етапі компіляції (запобігають `InvalidCastException`) та покращують продуктивність за рахунок усунення операцій упаковки та розпаковки (`boxing`/`unboxing`) для значущих типів (value types).
