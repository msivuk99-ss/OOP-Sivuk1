# Лабораторна робота №4: Наслідування. Ключові слова base, override, virtual. Приховування членів (new)

**Тема:** Наслідування. Ключові слова base, override, virtual. Приховування членів (new).  
**Мета:** Навчитися створювати ієрархії класів, використовувати ключові слова `base`, `virtual`, `override` для реалізації поліморфізму, а також розуміти відмінності між `override` та приховуванням членів за допомогою `new`.  
**Варіант:** 8 (Ієрархія Device → Smartphone → Laptop)  

---

# Структура проєкту

Проєкт складається з базового класу `Device` та двох похідних класів `Smartphone` і `Laptop`.

* **`Device` (базовий клас)**:
  * Приватні поля: `brand`, `model`.
  * Публічні властивості: `Brand`, `Model`.
  * Конструктор для ініціалізації полів.
  * Віртуальний метод `PowerOn()` (для поліморфізму).
  * Невiртуальний метод `GetDeviceType()` (для демонстрації `new`).

* **`Smartphone` (похідний клас)**:
  * Додаткова властивість: `ScreenSize`.
  * Виклик конструктора базового класу через `base(brand, model)`.
  * Перевизначений метод `PowerOn()` за допомогою `override`.
  * Унікальний метод `MakeCall()`.
  * Прихований метод `GetDeviceType()` за допомогою `new`.

* **`Laptop` (похідний клас)**:
  * Додаткова властивість: `Processor`.
  * Виклик конструктора базового класу через `base(brand, model)`.
  * Перевизначений метод `PowerOn()` за допомогою `override`.
  * Унікальний метод `RunProgram()`.

  ## Контрольні запитання

1. **Що таке успадкування і яку проблему воно вирішує в ООП?**
   Це механізм, який дозволяє похідному класу успадковувати поля, властивості та методи базового класу. Воно вирішує проблему дублювання коду (DRY) та дозволяє будувати ієрархії сутностей.

2. **Для чого використовується ключове слово `base`? Наведіть приклади.**
   Використовується для доступу до членів базового класу з похідного. Наприклад: для виклику конструктора базового класу (`: base(brand, model)`) або викликання його методу (`base.PowerOn()`).

3. **У чому полягає різниця між `override` та `new` при перевизначенні методів?**
   `override` змінює реалізацію віртуального методу для всіх посилань (динамічний поліморфізм). `new` лише приховує метод базового класу — якщо викликати метод через посилання базового типу, виконається стара реалізація.

4. **Що станеться, якщо в похідному класі оголосити метод з таким же ім'ям, як у базовому, але без ключових слів `override` або `new`?**
   Код скомпільовується і спрацює так само, як з `new` (приховування), але компілятор видасть попередження (warning) про відсутність ключового слова `new`.

5. **Чи можна перевизначити (`override`) невіртуальний (`non-virtual`) метод? Чому?**
   Ні, не можна. Перевизначити можна лише методи, явні позначені як `virtual`, `abstract` або вже `override`, оскільки компілятор повинен створити таблицю віртуальних методів (VMT).
