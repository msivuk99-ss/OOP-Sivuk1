Лабораторна робота No1
Тема: Створення першого проєкту. Класи, об’єкти, конструктори та деструктори.
Середовище розробки.
Мета
Ознайомитися з середовищем розробки, навчитися створювати класи та працювати з базовими
елементами ООП у C#. Налаштувати середовище розробки.

Контрольні запитання
1. Клас — це шаблон або «креслення», що описує структуру та поведінку майбутніх сутностей. 
Об’єкт — це конкретний екземпляр цього класу, створений у пам’яті за цим шаблоном. Всі 
об’єкти одного класу мають однакову структуру, але власні значення даних.

2. Конструктори використовуються для ініціалізації об’єкта під час його створення (присвоєння
початкових значень полям, виділення ресурсів тощо). Клас може існувати без явно написаного
конструктора — у такому разі компілятор автоматично створює стандартний конструктор за замовчуванням без параметрів.

3. Приватне поле доступне лише всередині самого класу і приховане від зовнішнього світу, а публічна властивість надає
контрольований доступ (читання/зміна) до даних класу ззовні. Інкапсуляція потрібна для захисту внутрішніх даних
об’єкта від некоректних змін, приховування деталей реалізації та забезпечення стабільності роботи програми.
